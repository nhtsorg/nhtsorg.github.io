NHTS WEBSITE - COMPLETE PACKAGE - HOW TO PUT IT LIVE (10 min, free)

WHAT'S INSIDE (nothing to add - photos included)
  index.html   your new homepage (the v2 design)
  photos.html  full photo gallery - 27 real visit photos
  img/         all photos, web-optimized

GO LIVE ON GITHUB PAGES
1. github.com -> sign in (or create a free account for the club,
   e.g. username "nhtsorg").
2. New repository -> name it EXACTLY:  nhtsorg.github.io
   (if your username is different, use YOURUSERNAME.github.io)
   -> Public -> Create repository.
3. On the new repo page click "uploading an existing file"
   -> drag in index.html, photos.html, and the img folder -> Commit changes.
4. Wait 1-2 minutes. Your site is live at:
   https://nhtsorg.github.io
5. Put that link in your Instagram bio.

AFTER LAUNCH
- "Request a visit" / "Join your branch" buttons currently open an email
  to nhtsorg@gmail.com. Once you fix the Google Form language
  (Google Forms -> your form -> it must display in English), open
  index.html in any text editor and replace the two "mailto:..." links
  with the form URL.
- To update photos later: add/remove jpgs in img/ and edit photos.html.
- Custom domain later: buy nhts-volunteering.com (~$12/yr) ->
  repo Settings -> Pages -> Custom domain.
